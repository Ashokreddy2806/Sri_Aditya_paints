# Sri Aditya Paints

Marketing website for **Sri Aditya Paints**, a Berger Paints and JSW Paints dealer in Narasaraopeta, Andhra Pradesh.

## Highlights

- Responsive English and Telugu storefront
- Berger and JSW product collection guides
- Links to the official colour catalogues, visualisers, and paint calculator
- Instant tinting enquiry flow for eligible 1 kg–20 kg packs
- Quote, consultation, repeat-order, and touch-up enquiry flows
- Store location and local-business search metadata

## Run locally

This is a static website: no build tooling is needed. Open `index.html` in a browser, or serve the repository using any static-file server.

## Deploy

Upload the repository contents to Netlify, GitHub Pages, or another static hosting provider. The homepage must remain at the repository root as `index.html`.

## Before production launch

- Add the business WhatsApp/phone number to the WhatsApp links in `script.js`.
- Confirm delivery area, payment options, business hours, and product/pack pricing.
- Replace placeholder gallery and testimonial content with approved customer content.
- Verify all brand-product text and product imagery against current dealer-authorised material.

## Assets

The supplied logo and owner photographs are stored in `assets/Images/` and are used in the header, hero, footer, and gallery. Product and brand names remain the property of their respective owners.
